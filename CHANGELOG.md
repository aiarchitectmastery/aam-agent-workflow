# Changelog

All notable changes to this repository are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the repository uses [Semantic Versioning](https://semver.org/).

## [2.0.0] — Unreleased

### Added

- First public release as a GitHub template repository.
- `.aam/workflows/core-workflow.md`: the PRD → PLAN → TASK → IMPLEMENTATION
  procedure with mandatory human checkpoints.
- `.aam/templates/`: PRD, PLAN, TASK and bounded-task templates and the
  IMPLEMENTATION review checklist.
- `.aam/prompts/`: fresh-session handoff prompts and agent guidance review
  prompts, including an appendix with the exact prompts from the AAM
  agent-guidance demo.
- `.aam/README.md` and `agent-workflow/README.md`: what each folder is for.
- Apache License 2.0 (`LICENSE`) and a `NOTICE` file with a trademark notice.

### Changed (relative to the AAM Starter Kit 3.1)

- Files reorganized into the AAM reference structure.
- `TASK-prompt-template.md` renamed to `TASK-template.md`.
- Template and prompt content is unchanged apart from the appendix above.

### Lineage

- This repository succeeds the downloadable AAM Starter Kit (versions 1.0 to
  3.1). The kit keeps its own version line on aiarchitectmastery.com. This
  repository starts at 2.0.0 as the second generation of the AAM workflow
  resources.
